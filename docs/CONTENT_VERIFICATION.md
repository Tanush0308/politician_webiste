# Content Verification

The following claims and data points require verification from the client before the website goes live. 

| Claim / Data Point | Source | Status | Action Required |
| :--- | :--- | :--- | :--- |
| Exact Slogans (e.g., "कामं बोलतात", "लोकांमध्ये. लोकांसोबत.") | Observation from similar sites | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Impact Numbers (e.g., 500+ Janasanvad, 120+ Villages) | Placeholder | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Biography details (Date of birth, education, early career) | Web search / Wikipedia | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Specific Timeline Dates (Zilla Parishad entry, specific milestones) | General knowledge | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Specific Project Budgets and Beneficiaries | N/A | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Assembly Questions (Exact text and status) | N/A | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Awards and Honours (Names, Years, Issuing Bodies) | N/A | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Official Social Media Handles (Instagram, Facebook, Twitter, YouTube) | Web search | Unverified | [CLIENT VERIFICATION REQUIRED] |
| Office Addresses and Phone Numbers | N/A | Unverified | [CLIENT VERIFICATION REQUIRED] |

**Important Note for Developers:** Do not hardcode these as verified facts. Use a CMS or a central `site.config.ts` so they can be easily updated once verified by the client.
